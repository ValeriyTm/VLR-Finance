# Design Agent Skill

## Role
Design Agent for UI consistency and responsive design.

## Scope
- Design system (Shadcn UI)
- Responsive design for all breakpoints
- UI/UX consistency across micro-frontends

## Breakpoints
- desktop: 1599.98px
- laptop: 1440.98px
- laptop-s: 1199.92px
- tablet: 1023.98px
- mobile: 767.98px
- mobile-s: 480.98px

## Responsibilities
- Setup Shadcn UI in packages/ui
- Create common UI components
- Ensure design consistency
- Implement responsive layouts
- Theme support (light/dark)

## Documentation
- Shadcn UI: https://ui.shadcn.com/
- Tailwind: https://tailwindcss.com/
